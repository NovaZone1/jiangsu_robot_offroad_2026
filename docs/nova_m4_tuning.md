## 烧录与连接

1. 关闭 Nova 串口及旧桥接，断电后将右后轮电机线及编码器线接 M4，装好该路电驱，固定车体并架空车轮。
   M4 PWM 为 PE13/PE14（TIM1 CH3/CH4），编码器 PB5/PB4（TIM3 CH2/CH1）。
   沿用已验证方向：M4 原始编码器计数不取反，不额外交换 A/B 或修改引脚映射。
2. DAPLink 烧录 `MDK-ARM/nova_m4_ai_100rpm_69pct.hex`，运行并 RESET。四轮应保持停止。
3. 运行 `tools/ble_bridge/Restart-Bridge.cmd`，按提示等待 READY。Nova 打开 COM12、115200、8N1、无流控。
   COM11 用于桥接，COM5 是 DAPLink。
4. 串口页选字符串、CRLF，发送一次 `LOOP:4`，再发 `PID?`。
   应返回 `OK:LOOP:4` 和 `PID:0.001200,0.008000,0.000000`。

## 调参

AI 页面点击“加载方案”，选择 [M4 专用方案](nova_m4_520_100rpm_69pct_profile.json)，确认 M4、CH4、0→100 RPM。
不要加载其他轮子的档案。

| 项目 | 设置 |
| --- | --- |
| 模式 / 通道 | PI，Kd 固定为 0 / CH4 |
| 基准 PID | 0.0012 / 0.008 / 0 |
| 初始 / 阶跃目标 | 0 / 100 RPM |
| 输出绝对值上限 | 0.69 |
| 实际转速范围 | -120～150 RPM |
| Kp / Ki 范围 | 0.0002～0.01 / 0.001～0.05 |
| 采集 / 最大试验数 | 5 秒 / 8 轮，包含最优复测 |
| 下位机控制周期 | 10 ms |
| 每轮最大变化 | 20%，绝对变化约束沿用此前档案 |
| 心跳 / 遥测超时 | 1 秒 |

选择“每轮确认”，点击“自动试验 / Start”。第一轮确认轮子前进方向和反馈正常后，再逐轮确认。
PID 页面选择 CH4 看转速，不从其他页面同时下发参数或目标。
完成后导出报告。接受最优只写设备 RAM，RESET 恢复本次基准；根据报告另行决定固化参数。

## 原保护

方向异常、无运动、超速、反馈/驱动失败、命令超时、50 ms 调度间断、停稳互锁和故障锁定均保留。
Nova 调参仍保留心跳看门狗、通信错误停机及 45 秒单轮硬上限。
STOP 禁能所有轮子，不清除故障；重新启动需通过原最少 1 秒滑行、低于 6 RPM 持续 100 ms、3 秒等待上限。
故障后不自动恢复运动。停止后先读取 `MotorSafety.status_.fault`、`MotorSafety.status_.failed_port`、
`NovaLink.trial_fault_`；M4 端口为 4。排查原因后再 RESET、重启桥接，不通过关闭保护继续试验。
