# 四轮电机保护

`FrameComponets/Apps/MotorProtection` 是由临时试车提取的正式保护模块，实例名 `MotorSafety`。
默认任务在应用控制前调用 `BeforeControl()`，电机测速后调用 `AfterControl()`。
保护模块不产生目标、不使能电机；异常禁能四轮并锁定首个故障及端口，不自动重试。

## 保留的阈值

| 项目 | 行为 |
| --- | --- |
| 调度间隔 | 电机使能或正在等待停稳时，间隔达到 50 ms 在下一次应用输出前停车 |
| 反馈/驱动 | 使能电机反馈过期或任一路驱动故障，禁能四轮；DcMotor 反馈有效期仍为 50 ms |
| 方向 | 非零目标开始/方向改变后允许 500 ms，连续 3 个新测速样本反向且超过 3 RPM 时停车 |
| 无转速 | 非零目标下低于 3 RPM 持续 1500 ms 停车；同方向速度调整不重置这个计时 |
| 超速 | 新鲜原始反馈绝对值超过 400 RPM 停车 |
| 命令 | DcMotor 原 250 ms 命令过期、非法值、限幅及输出失败保护保留 |
| 停稳等待 | 至少滑行 1000 ms，四轮低于 6 RPM 持续 100 ms，最长等待 3000 ms |

正常禁能、零目标不会触发无转速；未校准的灰度保持原自检等待，不伪造有效数据。
原始反馈用于保护，滤波反馈仅用于 PID。400 RPM 是原试车超速阈值，不是推荐运行速度。
该模块依赖周期执行，CPU 暂停期间无法停车；不替代电流检测、硬件过流或物理急停。

## 停稳后换向

应用需要换向时，在同一默认任务中调用 `MotorSafety.RequestCoastStop()`。
此调用立即禁能四轮，框架停止原应用动作并保持停车，继续采样和保护。
等待 `MotorSafety.CanResumeAfterCoast()` 为 true，再显式 `ReleaseCoastStop()`。
释放只取消等待，不自动使能或恢复应用；后续仍需要合法的应用启动请求和新的速度目标。
不要在等待阶段 Enable / SetSpeed，也不要绕过控制框架从中断写输出。

停稳反馈丢失、未停稳超过 3 秒或恢复前又检测到运动，均不能直接继续换向。
AT8236 仍采用双低滑行，不是主动刹车。通用驱动原 2 ms 换向间隔也保留。

## 故障与恢复

Keil Watch 可查看 `MotorSafety.status_` 的 `fault`、`failed_port`、`coast`，或通过 `GetStatus()` 读取。
端口 1～4 分别为 M1 左前、M2 左后、M3 右前、M4 右后；端口 0 表示整体时序/停稳问题。

先排除接线、电源、方向或反馈故障，保持四轮禁能；有 DcMotor 故障时显式 ClearFault。
之后可在同一任务显式重新 Init 保护模块，重新执行应用校准/自检及启动流程。
Init 不会自动清除驱动故障，不会自动 Enable。复位也会重新初始化，但不是排故的替代操作。

## 验证记录

`tests/frame/motor_protection_tests.cpp` 编译真实保护实现，覆盖正反向、零目标、方向错误、
无转速、超速、反馈丢失、命令超时、驱动故障、调度中断、故障锁定、计时回绕及停稳等待。
全部主机回归及 Keil V6 完整编译通过，0 Error / 0 Warning；清理后的整车保护等待上板验证。
