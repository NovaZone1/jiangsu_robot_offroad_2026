> 当时固件为 [M4 持续 100 RPM、Nova 只读监视](motor_m4_continuous_test.md)，M3 禁能并保留新 PID 0.001176/0.013926/0。
> 下文保留 M3 第一次调参操作；恢复 M3 AI 模式需要重新选择端口并编译，档案基准须更新为上述新 PID。

本页历史 AI 模式选择 `MOTOR_CONTINUOUS_TEST=0`、`NOVA_MOTOR_TUNING=1`、`NOVA_TUNING_PORT=3`。
右前轮 M3 对应 CH3；M1/M2/M4 每周期禁能。
上电、RESET、连接、查询、加载档案均不自动试转；仅 Nova 配置、停稳检查通过后显式启动 M3。

## 烧录与连接

1. 关闭 Nova 串口，停止旧桥接。M3 电机线和编码器线均接板上 M3，装好电驱，架空固定车轮。
   保留已验证的方向：PWM PE9/PE11、TIM1 CH1/CH2；编码器 PA0/PA1、TIM5。
2. DAPLink 下载当前 Keil 工程，或烧录 `MDK-ARM/nova_m3_ai_tuned_69pct.hex`，然后 RESET。
   电机应保持停止，不会恢复先前 M1 的持续试转。
3. 运行 `tools/ble_bridge/Restart-Bridge.cmd`。看到 READY 后，Nova 打开 COM12、115200、8N1、无流控。
4. 字符串、CRLF 发送一次 `LOOP:3`，再发送 `PID?`。
   应返回 M3 初值 `PID:0.001283,0.011104,0.000000`。桥接窗口的旧 LOOP:1 示例不适用于本次调参。

## 调参

加载 [M3 专用档案](nova_m3_520_tuned_100rpm_69pct_profile.json)，不要加载 M1 档案。

| 项目 | 设置 |
| --- | --- |
| 通道 / 模式 | CH3 / PI，Kd 锁定为 0 |
| M3 固件初值 PID | 0.001283 / 0.011104 / 0 |
| 目标阶跃 | 0→100 RPM |
| PWM / 积分限幅 | 0.69 / 0.69 |
| 控制 / 遥测周期 | 10 ms / 20 ms |
| 采集 | 阶跃前 1 s，阶跃后 5 s |
| 初始稳定条件 | ±3 RPM 持续 1.2 s，最长等 8 s |
| Kp / Ki 范围 | 0.0002～0.01 / 0.001～0.05 |
| 最大试验数 | 8，包含最优参数复测 |
| 单次最大变化 | 20%，绝对变化约束沿用 M1 档案 |
| 实际转速边界 | -120～150 RPM |
| 心跳 / 持续饱和阈值 | 1 s / 1 s |

选择“每轮确认”，点击“自动试验 / Start”。先看第一轮方向、响应和评分，再确认下一轮。
PID 页选择 CH3 看轮速，无需手工循环发送目标或心跳，不从其他页面同时写参数。
最优复测通过后接受并导出报告；Nova 写入只保存在 RAM，复位恢复 M3 基准，固化需另行确认。
如果等待接受期间通信异常中止，不取消保护；保存已完成试验的数据并排查通信。

## 原保护与 M1 参数

MotorProtection 和驱动不改：无运动、方向、超速、反馈失效、驱动异常、调度/命令超时、
滑行停稳互锁与故障锁定继续有效。设备保持 69% 硬上限、150 RPM 目标绝对上限、45 s 单轮时限，
UART 丢帧/发送失败、心跳超时等仍停止并锁定。STOP 不清除故障。
故障帧为 CH3；Keil 可看 `MotorSafety.status_.fault`、`failed_port`、`NovaLink.trial_fault_`。

M1 固化参数 0.000957/0.009191/0 保留，本次拒绝非 CH3 的改 PID、配置及运动命令。
完整数据见 [M1 实测归档](motor_pid_20261011_m1/README.md)。M3 已按本次 [8 轮实测记录](motor_pid_20261011_m3/README.md) 固化新参数。旧非 tuned 档案保留作原始基准。

恢复 M1 AI 需将 `NOVA_TUNING_PORT=1` 后重新编译。恢复比赛需关闭本地测试及 `NOVA_MOTOR_TUNING`。
