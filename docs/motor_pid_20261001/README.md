# 四轮速度 PI 实测记录

2026-10-01，通过板载 CH340（COM3，115200 8N1）完成四轮正反转自动调参。
用户确认四轮架空、电机电源打开、FlyMCU 关闭，并在本轮开始前按 RESET。
测试每次只驱动一轮；目标为输出轴 40、60 RPM，每个方向、每个目标重复验证两次。
电池电压未实测。本记录不能代替落地、四轮同时运行或比赛负载验证。

## 结果

共 144 次完整试验，得到 8 组参数；32 次最终重复验证全部 PASS。
验证中最大平均稳态误差为 0.451%，最大超调为 8.75%，最长稳定时间为 0.85 秒。
稳态滤波 RPM 的最大标准差/目标转速为 2.105%。
稳定时间采用持续保持在目标 ±max(3 RPM, 5%) 内的判据；误差、超调和波动指标基于滤波转速。
这些是最终参数的验证指标，搜索阶段包含被排除的较差候选。

Kd 均为 0。PI 单位基于输出轴 RPM、秒和占空比；反馈低通时间常数为 0.03 秒。
实际 PWM 限幅和积分限幅均为 0.69；驱动 `deadzone_duty` 必须为 0。
不能只复制 Kp/Ki，同时保留旧的 2000/3600 死区补偿。
正反转分开配置，切换参数应先禁能，不能每次更新目标都清积分。

本轮结束后另外执行了仅 HELLO/STOP 的检查，连续三个空闲帧均为 NONE、四轮 0 RPM。
这是当时调参会话的停车检查。临时入口现已删除；当前固件恢复框架调度，上电四轮禁能。
正式参数配置位于 `FrameComponets/Apps/Inc/MotorSpeedProfiles.hpp`，不会自动启动电机。

## 固件和通信验证

本轮握手身份为 `MOTOR_TUNE_V1,TICKFIX2`，使用用户已烧录的 `MDK-ARM/motor_pid_tuning_tickfix.hex`。
该 HEX 的 SHA256：`EB6ED669C6511AF14747BEBCCB5C94761D9BF0E4606F679B95B2677FA63508C8`。
对应 V6 Rebuild 为 0 Error、0 Warning；主机 C/C++ 回归和 Python 调参回归通过。

此前心跳误超时来自 HAL tick 跨毫秒时，旧时间减去更新后的心跳时间产生无符号下溢。
TICKFIX2 在处理串口后重新取当前时间，保留超时停机并添加跨 tick 回归。
本轮全部完成，无通信超时；同一试验内主机最大 PING 发送间隔约 60.265 ms。
主机发送日志只证明写入串口，完整遥测和 DONE 回复另行证明试验完成。

后续应先验证四轮共同供电、安装负载及地面条件，再确定比赛使用的速度范围。
