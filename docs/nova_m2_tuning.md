## 烧录与连接

1. 关闭 Nova 串口及旧桥接，断电后确认左后轮电机线和编码器线均接 M2，并装好电驱。
   M2 PWM 为 PC8/PC9（TIM8 CH3/CH4），编码器为 PA15/PB3（TIM2 CH1/CH2）。
   沿用已验证方向和引脚重映射，不改线序；固定车体、架空车轮。
2. DAPLink 烧录 `MDK-ARM/nova_m2_ai_100rpm_69pct.hex`，运行并按 RESET。此时四轮应保持停止。
3. 双击 `tools/ble_bridge/Restart-Bridge.cmd`，等待 READY。Nova 打开 COM12、115200、8N1、无流控。
   COM11 给桥接使用，COM5 是 DAPLink。
4. 串口收发页选择字符串、CRLF，发送一次 `LOOP:2`，再发 `PID?`。
   应返回 `OK:LOOP:2` 及 `PID:0.001200,0.008000,0.000000`。

## Nova AI 调参

在 AI 页面点击“加载方案”，选择 [M2 专用档案](nova_m2_520_100rpm_69pct_profile.json)。
不要加载 M1/M3 档案，确认页面标注 M2、CH2、0→100 RPM。

| 项目 | 设置 |
| --- | --- |
| 模式 / 通道 | PI，Kd 固定为 0 / CH2 |
| 基准 PID | 0.0012 / 0.008 / 0 |
| 初始目标 / 阶跃目标 | 0 / 100 RPM |
| 输出绝对值上限 | 0.69 |
| 实际转速下限 / 上限 | -120 / 150 RPM |
| Kp 范围 / Ki 范围 | 0.0002～0.01 / 0.001～0.05 |
| 单轮采集 / 最大试验数 | 5 秒 / 8 轮，包含最优参数复测 |
| 下位机采样周期 | 10 ms |
| 最大单次参数变化 | 20%，绝对变化约束沿用之前档案 |
| 心跳 / 遥测超时 | 1 秒 |

选择“每轮确认”，点击“自动试验 / Start”。第一轮确认实际前进方向正常，再逐轮点击“下一轮”。
PID 页面选择 CH2 查看轮速；自动试验期间不从其他页面同时发送 PID/目标。
试验结束导出报告，后续再根据报告固化 M2 最优参数。Nova 接受最优只写 RAM，复位恢复本次基准。

## 原保护保持有效

方向异常、无运动、超速、反馈/驱动故障、命令超时、50 ms 调度间断及停稳互锁全部保留。
Nova 调参仍有设备端心跳看门狗、通信错误停机、45 秒单轮硬上限及故障锁定；STOP 不清除故障。
每次启动必须通过原停稳互锁（最少 1 秒滑行、低于 6 RPM 持续 100 ms、3 秒等待上限）。
保护触发后四轮禁能，不自动重新运行。保留现场后查看 `MotorSafety.status_.fault`、
`MotorSafety.status_.failed_port`、`NovaLink.trial_fault_`；本次故障端口应为 2。
排查原因后再 RESET 并重启桥接；不通过关闭保护继续试验。
